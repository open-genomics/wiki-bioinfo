# 变更记录：修复 Head 覆盖层的重复 meta 与站点名标题

- 日期：2026-11-08
- 变更类型：SEO 元数据修复 + 静态校验

## 内容
- `src/components/overrides/Head.astro` 不再重复输出 Starlight 内置 Head 已有的
  标签（`canonical`、`og:title` / `og:description` / `og:url` / `og:type` /
  `og:locale` / `og:site_name`、`twitter:card`），只保留 Starlight 未提供的
  `og:image`、`og:image:alt`、`twitter:title` / `twitter:description` /
  `twitter:image`、`author`、`keywords`、`theme-color` 与首页 WebSite 结构化数据。
- 页面标题与描述改为从 `Astro.locals.starlightRoute.entry.data` 读取。Starlight
  渲染 `<Head />` 时不传 props，原先从 `Astro.props` 读取导致每页
  `og:title` / `twitter:title` 恒为站点名。
- 新增 `scripts/checks/check-head-meta.mjs`，检查构建产物中单例 meta 是否重复、
  `og:title` / `twitter:title` 是否等于页面标题、必需标签是否齐全且内容一致；
  接入 `npm run check`（`check:head`）。

## 影响
- 每个页面的社交分享标题恢复为页面标题，例如「编辑距离」而非「BioInfo Wiki」。
- 不再出现两个 `canonical` 或内容互相矛盾的 `og:title` / `og:description`。
- 后续若有人再次在覆盖层重复输出 Starlight 标签，`npm run check` 会失败。

## 验证
- 修复前：`node scripts/checks/check-head-meta.mjs` 对 HEAD 构建报
  2098 处问题（重复 meta、标题为站点名）。
- 修复后：`npm run check` 通过（`astro check` 0 errors / 0 warnings，
  175 个页面构建成功，head 校验通过）。
- `npm run build` 通过，共构建 175 个页面。
