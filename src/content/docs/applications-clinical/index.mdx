本板块关注从变异到临床决策：如何检测、过滤、注释和解释与疾病相关的遗传变异。如果关注的是从数据到生物学发现，见[组学应用](../applications-omics/)。

这一部分聚焦偏临床解释的应用方向：变异检测（DNA-seq variant calling）、临床变异解释（ACMG 框架、CNV/SV 证据）与结构生物信息学（蛋白结构、AlphaFold、结构比对）。这些方向对证据标准、注释体系与参考版本更为敏感，与方法层和数据层紧密关联。
