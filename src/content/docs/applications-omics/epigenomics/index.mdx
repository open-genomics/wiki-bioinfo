表观基因组学（Epigenomics）研究**不改变 DNA 序列的可遗传调控变化**，回答"同一基因组为何能产生不同细胞身份、并响应环境"这一中心法则无法单独解释的问题。它有三大支柱：**DNA 甲基化**（CpG 胞嘧啶修饰，常与启动子沉默相关）、**组蛋白修饰**（构成调控染色质状态的"组蛋白密码"）和**染色质可及性**（开放区域允许转录因子进入）。这些标记可逆、可在细胞分裂中遗传，是细胞记忆与命运决定的分子基础，其异常与肿瘤、神经发育疾病等密切相关。

## 如何阅读本章

建议先建立两种核心检测技术的认知：[ChIP-seq](./chip-seq-overview) 用抗体富集回答"某个蛋白/修饰在哪里结合"，[ATAC-seq](./atac-seq) 用 Tn5 转座酶回答"哪里开放、哪些调控元件潜在活跃"。再进入 [DNA 甲基化](./dna-methylation) 理解第三种支柱及其 WGBS/DMR 分析。算法层面，[MACS2 峰调用](./macs2-peak-calling) 是 ChIP-seq 与 ATAC-seq 共用的峰识别统计框架；DMR 检测与 footprinting 的算法细节已分别并入 DNA 甲基化与 ATAC-seq 页面。
