单细胞组学（Single-cell Omics）把"整体"打散成"个体"，在细胞分辨率下测量转录组（scRNA-seq）、染色质可及性（scATAC-seq）乃至多模态（Multiome），揭示 bulk 平均无法呈现的细胞类型、发育轨迹与稀有亚群。它的核心问题是：在极度稀疏（dropout）、高维、含批次效应的数据中，如何稳健地识别细胞状态并推断其关系。

## 如何阅读本章

建议先从 [scRNA-seq 总览](./scrna-seq-overview) 建立"实验设计 → 数据处理 → 聚类注释"的完整流程认知，再按兴趣深入具体环节：数据生成机制看 [Barcode 与 UMI](./cell-barcode-umi)，分群与可视化看 [聚类与 UMAP](./clustering-and-umap)，动态过程看 [轨迹推断](./trajectory-analysis)，数据质量看 [doublet 检测](./doublet-detection)。若关注组织空间定位，进入空间转录组三篇（总览、spot 与单细胞对比、去卷积与映射）。通用聚类算法（层次聚类、k-means、CAST）已移至[核心方法 · 聚类算法](../../core-methods/algorithms/clustering-algorithms/)。
