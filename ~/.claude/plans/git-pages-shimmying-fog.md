# Git Pages 阅读路径卡片布局问题分析

## 问题描述

三条阅读路径（初学者路径、算法路径、任务驱动路径）的卡片高度不一致，且水平未对齐。

## 问题分析

### 相关文件

| 文件 | 作用 |
|------|------|
| `src/components/docs/PathCard.astro` | 卡片组件定义 |
| `src/content/docs/index.mdx` | 首页，第 72-85 行 |
| `src/styles/custom.css` | 第 236-258 行 |

### 根本原因

**1. 卡片内容高度不同**

三张卡片的 steps 内容长度差异明显：

```jsx
// 初学者路径 - 短文本（4 个简短步骤）
steps={['导论', '基础与数学', '数据与资源', '分析方向']}

// 算法路径 - 长文本（包含"回到分析方向验证方法位置"等）
steps={['导论中的算法入口', '基础与数学', '核心方法', '回到分析方向验证方法位置']}

// 任务驱动路径 - 中等文本
steps={['选择一个分析方向', '回看相关数据与资源', '追溯到核心方法', '再补基础与模型']}
```

**2. `align-items: stretch` 的行为导致视觉不一致**

```css
.home-path-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  align-items: stretch;  /* 所有卡片拉伸到最高那张的高度 */
}
```

由于"算法路径"内容最长，它撑开了高度。`align-items: stretch` 让其他两张卡片也被拉伸到相同高度。

**视觉上的问题**：
- "初学者路径"卡片内容少，底部留白多，显得"被撑高"了
- "算法路径"卡片内容刚好填满，看起来正常
- 用户感知到的是"初学者路径比后面的卡片高"（实际是留白多）

**3. `<ol>` 元素 margin 不完整**

```css
.home-path-card ol {
  margin: 0.75rem 0 0;  /* 只有顶部 margin，没有底部 margin */
}
```

这导致 `<ol>` 与卡片底部边缘之间没有间距，留白分布不均。

**4. 水平不对齐的可能原因**

Grid 布局设置正确，但可能是用户观察到的"不对齐"是指：
- 卡片顶部水平对齐了，但由于高度差异，底部不对齐
- 或者用户指的是卡片内部元素（h3、ol）的水平位置不一致

## 解决方案

### 推荐方案：修复 margin + 保持 stretch

```css
/* 文件：src/styles/custom.css */

.home-path-card ol {
  margin: 0.75rem 0;  /* 添加底部 margin，让留白均匀 */
}
```

这是最小改动，让卡片内部留白分布更均匀，视觉上更协调。

### 可选方案：限制卡片高度

如果希望卡片更加紧凑，可以设置统一的最小高度：

```css
.home-path-card {
  min-height: 8rem;
}
```

## 修改文件

- `src/styles/custom.css` 第 256-258 行

## 验证方法

1. 启动开发服务器：`npm run dev`
2. 访问首页查看三条阅读路径卡片
3. 检查卡片底部留白是否均匀
4. 运行 `npm run check` 确保无问题
